# ADR-007 — Overlay, coexistence and system-of-record in one code base

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 2, 21, 68

## Context

Municipalities cannot switch systems overnight; the first pilot runs alongside the existing system of record.

## Decision

`system_of_record`, `source_system` and `source_record_id` are columns on the canonical record, and field ownership is declared per integration. Switching mode is a data change, not a deployment.

## Consequences

Every write path must consider who owns the field. No general last-write-wins is permitted.
