# ADR-008 — Explicit provenance on every external value

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 21, 22, 23, 24, 141

## Context

A caseworker must be able to answer where a value came from and how authoritative it is, and an AI derivation must never silently replace a register value.

## Decision

Values carry provenance (source system, record id, version, timestamps, mapping version, authoritative level). `resolveValue()` and the data-source registry rank AUTHORITATIVE > REFERENCE > ADVISORY > DERIVED > AI_DERIVED, and conflicts of equal rank are surfaced rather than resolved silently.

## Consequences

More storage and more UI surface, but a defensible answer to "varför står det så här?".
