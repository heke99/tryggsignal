# ADR-002 — Canonical data model with local extension points

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 20, 21, 22, 32

## Context

Legacy systems (ByggR, Vision, Nova, Castor) use different case models, and Boverket's national PBL classification is still evolving. Hard-coding today's structure would make both migration and future national alignment expensive.

## Decision

A canonical case/property/document model is the internal contract. Classification is versioned data (`core.classifications`, `classification_versions`, `classification_mappings`) with legacy/local/canonical/Boverket codes mapped explicitly.

## Consequences

New source systems are onboarded by adding a mapping version rather than by changing the core schema. Mapping versions must be retained for provenance.
