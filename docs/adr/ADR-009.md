# ADR-009 — PostgreSQL-first search

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 46, 47, 48, 49

## Context

Introducing OpenSearch early adds an operational component per municipality and a second place where authorization can leak.

## Decision

Search starts with tsvector/GIN, pg_trgm and PostGIS in the tenant's own database, with authority, information class and security scope on every indexed entity. pgvector is enabled only when semantic retrieval is actually implemented. OpenSearch requires a documented performance bottleneck first.

## Consequences

Search stays inside the RLS boundary. Scale limits must be measured (P30) before revisiting.
