# ADR-005 — Human-in-the-loop AI

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 75, 77, 78, 79, 143

## Context

AI output is probabilistic, and a building permit decision is an exercise of public authority.

## Decision

AI is an assistant: every finding carries evidence (document, page, model, prompt version, confidence), AI never writes directly to legally critical state, and a qualified human makes the final decision unless a municipality has explicitly enabled a deterministic, legally analysed automated flow. Document text is untrusted input and can never grant tools or change permissions.

## Consequences

AI features need an evidence UI ("visa varför") and an audit trail from the start; retrofitting them later is not possible.
