# ADR-012 — White-label through design tokens only

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 152, 153, 154, 186

## Context

Tenant-supplied CSS or JavaScript would be a cross-tenant XSS and exfiltration vector inside an authority system.

## Decision

Branding is a versioned row of tokens (colors, logos, labels, links, locale) validated for contrast before publication. No tenant JavaScript, no arbitrary HTML, no unrestricted CSS injection; the CSP allows only first-party scripts.

## Consequences

Some visual requests will require a product change rather than tenant configuration. That is the intended trade-off.
