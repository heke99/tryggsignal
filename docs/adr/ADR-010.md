# ADR-010 — Durable jobs on PGMQ

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 42, 43, 44, 45, 144

## Context

Document processing, integration delivery and archive generation must survive restarts and must not run inside a user request.

## Decision

Supabase Queues/PGMQ with a durable (logged) queue for legally critical work, a standard job envelope with idempotency key and correlation id, exponential backoff with a dead-letter state, and pg_cron limited to enqueueing work.

## Consequences

No Kafka or Temporal in the first architecture; queue depth and dead letters become first-class operational signals.
