# ADR-003 — No Docker in the normal development workflow

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 6, 3

## Context

Municipal IT environments and the development laptops used here cannot be assumed to run Docker, and `supabase start` would make local work depend on it.

## Decision

Development and testing run against hosted Supabase development/test projects. SQL is iterated remotely, verified, and then committed as a versioned migration under `supabase/migrations/`. No workflow requires Docker or Kubernetes.

## Consequences

Requires network access to a hosted project and disciplined migration hygiene; in exchange, onboarding is a clone plus `pnpm install`.
