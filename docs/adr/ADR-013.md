# ADR-013 — Host-bound sessions and explicit data-plane binding

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 153, 171, 179, 180, 181

## Context

A broad `.tryggsignal.se` cookie would let one municipality's host observe another municipality's session, and a client-supplied tenant id would defeat host resolution.

## Decision

Session cookies are host-bound (`__Host-` prefixed and tenant-named); the tenant comes only from the resolved host; and `assertDeploymentMatchesContext()` refuses to build a client when the resolved context and the deployment record disagree — there is no fallback to a default project.

## Consequences

Central login at `app.tryggsignal.se` requires a deliberate handoff to the tenant host rather than a shared cookie.
