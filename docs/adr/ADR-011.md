# ADR-011 — Wildcard and custom-domain tenant routing on one Vercel project

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 155, 157, 158, 205

## Context

Forty municipalities must not mean forty code bases, and each municipality wants its own domain.

## Decision

One Next.js code base serves `*.tryggsignal.se` and verified custom domains. `proxy.ts` (the Next.js 16 successor to middleware) normalizes the hostname, resolves reserved platform hosts first, then looks up an ACTIVE tenant domain and rewrites into `/t/<slug>/…`, forwarding the tenant context as request headers it always strips from the inbound request first.

## Consequences

Routing is not a security boundary on its own: every data operation re-checks tenant, data plane and RLS. Preview hosts resolve to the gateway and never serve a production tenant by host.
