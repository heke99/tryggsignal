# ADR-006 — Adapter-based integration with generic connectors first

- Status: Accepted
- Date: 2026-09-07
- Masterplan: 60, 61, 62, 134

## Context

Vendor APIs differ, licensing differs per municipality, and building five half-finished vendor adapters before the first real integration wastes effort and invites fabricated field mappings.

## Decision

A shared connector contract (healthCheck, listCases, getCase, …) with capability declaration. Generic REST/SOAP/SFTP/file/SQL connectors are built first; a vendor adapter is implemented only against verified documentation for a specific product version, with contract tests.

## Consequences

Missing vendor access is recorded as EXTERNAL_BLOCKED with an interface, configuration model and contract tests in place — never as a mocked production response.
